# News Explorer

About The Project

The concept of the app is straightforward: it sends a request to an API, which returns news articles. We then gather and process the news articles which can then be saved by the user to their private profile.

What was used?

    - HTML
    - CSS
    - JavaScript
    - React (Tools, Hooks, and Router)
    - JSX
    - Api integration
    - backend built with express.js
    - authorization
    - JWT
